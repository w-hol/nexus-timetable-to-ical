Importing the Events

Outlook for Mac

  1. Make sure that Outlook is in legacy mode, by going to File > Legacy Outlook, and make sure it is enabled
  2. In the bottom left navigation bar, click the calendar icon
  3. Drag and drop the .ics file from finder into the main calendar grid

Outlook for Windows

  1. On the left navigation bar, click the calendar icon
  2. Click File > Open & Export > Open Calendar > select your .ics file and click ok

Apple Calendar (Mac)

  1. Click File > Import..., select your .ics file and click import
